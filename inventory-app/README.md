# 在庫管理アプリ (inventory-app)

複数拠点の在庫管理、拠点間移動、サンプル品の払出・返却、請求書作成を行う簡易アプリです。
外部依存パッケージはなく、Node.js 22.13 以上の組み込み機能 (`node:sqlite`, `node:http`) だけで動きます。

## 起動

```bash
npm start              # http://localhost:3000
PORT=8080 npm start    # ポート変更
DB_PATH=/path/to/x.db npm start   # DB の場所 (既定: data/inventory.db)
npm test               # 自動テスト
```

## 機能

| 画面 | できること |
| --- | --- |
| 在庫 | 拠点別・品目別の在庫一覧、入庫・在庫調整、サンプル貸出中の一覧、移動履歴 |
| 移動・サンプル | 拠点間移動 / サンプル払出 (拠点→お客様) / サンプル返却 (お客様→拠点)、履歴 |
| 請求書 | 下書き作成・編集、発行 (採番と在庫引当)、入金済、取消 (在庫を戻す)、印刷 / PDF 保存 |
| マスタ | 拠点・品目・取引先の登録と編集 |

## 業務ルール

- **在庫は台帳で管理**: `stock_movements` に増減を記録し、残高は集計で求めます。移動は必ず「減る行」と「増える行」の 2 行で記録します。
- **保持先は拠点かお客様の 2 種類**: サンプルを払い出すと、在庫はお客様の保有数に移ります。返却されるまで「サンプル貸出中」に残ります。
- **在庫不足は登録不可**: 拠点や保有数を超える移動・出荷は 409 で拒否し、トランザクションごと取り消します。同じ品目の複数行は合算して判定します。
- **サンプル返却は貸出数まで**: お客様の貸出残を超える返却は拒否します。
- **請求書**
  - 下書きの間は在庫に影響しません。
  - 発行時に請求書番号 `INV-YYYYMM-0001` を採番し、出荷拠点の在庫を明細数量分減らします。
  - 取消すると在庫が戻ります。入金済にできるのは発行済のみです。
  - 単価を省略すると品目の標準単価を使います。消費税は 10% で、1 請求書単位で切り捨てます。
  - 下書きのみ編集・削除できます。

## API 概要

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET / POST / PUT | `/api/locations`, `/api/products`, `/api/customers` (`/:id`) | マスタ |
| GET | `/api/stock` | 拠点・取引先別の残高、サンプル貸出残 |
| POST | `/api/stock/adjustments` | 入庫 (正数量) / 在庫調整 (負数量) |
| GET | `/api/movements` | 在庫移動履歴 (最新 200 件) |
| GET / POST | `/api/transfers` | 移動・サンプル処理の一覧 / 登録 |
| GET | `/api/sample-loans` | お客様ごとのサンプル貸出残 |
| GET / POST | `/api/invoices` | 請求書の一覧 (`?status=`) / 下書き作成 |
| GET / PUT / DELETE | `/api/invoices/:id` | 詳細 / 下書き更新 / 下書き削除 |
| POST | `/api/invoices/:id/issue`, `/paid`, `/void` | 発行 / 入金済 / 取消 |

金額はすべて整数 (円) です。エラーは `{ "error": "..." }` の JSON で返します。

## 構成

```
src/
  server.js     エントリポイント
  app.js        ルーティングと静的ファイル配信
  db.js         SQLite のスキーマとトランザクション
  stock.js      在庫台帳 (残高・増減・入庫調整)
  transfers.js  拠点間移動・サンプル払出/返却
  invoices.js   請求書 (下書き・発行・取消・採番・税計算)
  masters.js    拠点・品目・取引先
  validate.js   入力検証
public/         画面 (HTML / CSS / JS, フレームワークなし)
test/           node:test によるテスト
```

## 制限事項 (現時点)

- 認証・権限管理はありません。社内の閉じたネットワークでの利用を想定しています。
- 入金消込は「入金済」フラグのみで、入金額や部分入金は扱いません。
- 請求書の発行元情報 (社名・住所・インボイス番号など) は未設定です。印刷物に載せる場合は追加が必要です。
- 税率は 10% 固定です。軽減税率には対応していません。
- サンプルの「売上への振替 (買取)」は未対応です。返却で戻すか、貸出残として残します。
